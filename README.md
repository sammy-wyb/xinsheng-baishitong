# AI 新生百事通 · 校园事务问答智能体

大学生 OPC 创新创业 AI Agent 赛道（T01）落地可运行项目。

## 一句话
把散落在各类通知里的校园事务（选课、报到、奖助学金、宿舍、生活服务）整理成**可核验知识库**，用自然语言提问，30 秒内给出**结论 + 办理步骤 + 所需材料 + 地点/入口 + 来源与核验日期**；没把握时**明确兜底转官方渠道**并登记问题。

## 怎么运行（无需联网、无需安装）
1. 直接双击根目录的 **`index.html`**，浏览器打开即可使用。
2. 或在项目目录运行 `start.cmd`（本地服务，便于分享给同学试用）。

## 功能模块
| 模块 | 说明 |
|---|---|
| 💬 智能问答 | 检索已核验知识库，输出结论/步骤/材料/地点 + 来源标注 + 无答案兜底 + 问题登记 |
| 🗂 办事流程 | 按类别浏览 55 条流程，支持关键词搜索 |
| 📊 高频统计 | 分类提问次数、未解决问题登记清单、可导出待补充清单 |
| ✅ 30 题自测 | 内置 30 题覆盖 5 类事务，实时输出准确率 / 来源标注完整率 / 无答案处理正确率 |
| 🚀 关于/OPC | 作品概览、知识库覆盖、OPC 特征、推广适配说明 |

## 目录结构
```
AI新生百事通/
├── index.html              # 主应用（双击即可运行）
├── start.cmd               # 可选本地服务
├── data/
│   ├── knowledge_base.json # 知识库（5 类 55 条，管理员维护）
│   ├── knowledge_base.js   # 内联知识库（离线运行用，由 json 生成）
│   └── test_30.json        # 30 题测试集
├── docs/                   # 作品介绍、用户手册、测试报告、架构说明
└── tests/
```

## 数据与合规
- 知识条目基于学信网、教育部、国家开发银行等**公开权威渠道**整理；校内具体事项已标注“需按本校官方通知核实”。
- 不采集学号/手机号等与问题处理无关的个人信息；试用自愿。
- AI 生成内容对外使用前需人工审核；来源与核验日期随条目保存，便于持续更新。
- 替换 `data/knowledge_base.json` 即可适配其他学校（推广适配性）。

## 对应 T01 验收标准
- ✅ 知识库覆盖 5 类校园事务、55 条（≥50 条）
- ✅ 预置 30 题测试，可运行计算准确率（内置自测）
- ✅ 每条回答注明来源与核验日期；无答案时正确转官方渠道并登记
- ✅ 高频问题统计供管理员补充知识库
