# 架构与 OPC 说明 · AI 新生百事通

## 系统架构（三层）
```
┌─────────────────────────────────────────────┐
│  表现层：index.html 网页（智能问答/流程/统计/自测） │
├─────────────────────────────────────────────┤
│  逻辑层：检索引擎（关键词+分类打分）＋ 无答案兜底  │
│         ＋ 来源标注 ＋ 问题登记 ＋ 高频统计          │
├─────────────────────────────────────────────┤
│  数据层：data/knowledge_base.js（5类55条，离线内联） │
│         data/knowledge_base.json（管理员维护）      │
│         localStorage（提问统计/未解决问题记录）       │
└─────────────────────────────────────────────┘
```

## 处理流程
1. 学生提出问题 → 2. 检索引擎在已核验知识库检索 → 3. 命中则输出“结论/步骤/材料/地点 + 来源与核验日期”；未命中则明确提示并引导官方渠道 → 4. 可登记未解决问题 → 5. 管理员核验高频问题、补充知识库并复测。

## OPC 特征（低成本启动 · 小团队协作 · AI 辅助执行 · 快速验证 · 持续迭代）
| 维度 | 体现 |
|---|---|
| 低成本启动 | 纯前端应用，双击运行，无服务器/无付费 API |
| 小团队协作 | 知识库/开发/测试/材料四线并行，FAQ 主表统一维护 |
| AI 辅助执行 | 自然语言检索 + 结构化流程输出 |
| 快速验证 | 内置 30 题自测，实时准确率 |
| 持续迭代 | 高频统计 + 未解决问题登记 → 补充知识库 → 复测 |

## 推广适配性
替换 `data/knowledge_base.json` 即可适配任意学校；每条含来源与核验日期，支持持续更新与标准化复制。

## 技术选型与来源声明
- 平台：纯 HTML/CSS/JavaScript 静态应用（可扩展接入扣子/文心等智能体平台与外部模型 API）。
- 数据来源：学信网、教育部《普通高等学校学生管理规定》、国家开发银行生源地助学贷款等公开权威渠道；校内具体事项标注“需按本校官方通知核实”。
- 隐私与合规：不采集无关个人信息；试用自愿；对外内容人工审核。
