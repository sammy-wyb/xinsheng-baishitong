# 用户手册 · AI 新生百事通

## 1. 启动
- **方式 A（最简）**：双击项目根目录的 `index.html`，浏览器打开即可，无需联网与安装。
- **方式 B（本地服务）**：双击 `start.cmd`，自动在浏览器打开 `http://localhost:8080/index.html`，便于分发给同学试用。

## 2. 智能问答
1. 在“智能问答”页底部输入框输入问题（如“怎么申请生源地助学贷款？”），回车或点“提问”。
2. 系统检索知识库，回答包含：**结论 / 办理步骤 / 所需材料 / 办理地点与入口 / 来源与核验日期 / 核验状态**。
3. 找不到可靠依据时，会提示“暂未找到可核实的信息”，并建议通过学校官方渠道核实；点“登记该问题”即可记录待补充。

## 3. 办事流程
在“办事流程”页可按关键词搜索（如“学信网”“报修”“助学贷款”），点“查看详情”展开完整步骤与材料。

## 4. 高频统计
“高频统计”页展示：知识库条目数、累计提问数、未解决问题数、各类事务被提问次数、未解决问题登记清单。管理员可“导出待处理清单 (JSON)”，据此补充知识库。

## 5. 30 题自测
进入“30 题自测”页，点“运行 30 题自测”，系统对 30 道覆盖 5 类事务的问题逐题判定，输出回答准确率、来源标注完整率、无答案处理正确率，并列出逐题结果。

## 6. 管理员：维护知识库
编辑 `data/knowledge_base.json`（5 类、每条含 q/kw/answer/steps/materials/place/source/sourceUrl/date/verified/note），保存后用以下命令生成离线运行用的内联 JS：

```
python -c "import json;d=json.load(open('data/knowledge_base.json',encoding='utf-8'));open('data/knowledge_base.js','w',encoding='utf-8').write('window.CAMPUS_KB = '+json.dumps(d,ensure_ascii=False)+';')"
```

替换该文件即可适配其他学校。
